# Proyecto 1 - Airline Cargo Optimization

## Descripción

Este proyecto desarrolla un modelo de optimización matemática basado en Programación Lineal Entera Mixta (MILP), cuyo objetivo es seleccionar la mejor combinación de carga para un vuelo de carga, maximizando el ingreso total y respetando las restricciones operacionales del avión.

---

## Industria

Transporte Aéreo

---

## Área

Carga Aérea (Cargo)

---

## Tipo de problema

Optimización Matemática

---

## Modelo

MILP (Mixed Integer Linear Programming)

---

## Solver

Google OR-Tools (SCIP)

---

## Lenguaje

Python

---

## Objetivo General

Diseñar un modelo matemático capaz de determinar qué cargas deben ser transportadas para obtener el mayor beneficio económico posible sin sobrepasar las capacidades del avión.
