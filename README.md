# 📊 Portafolio de Investigación de Operaciones y Optimización

Bienvenido a mi portafolio profesional de **Investigación de Operaciones (Operations Research)**, donde desarrollo soluciones de optimización matemática aplicadas a problemas reales de negocio utilizando Python y herramientas especializadas.

El objetivo de este repositorio es demostrar la capacidad de modelar, resolver e implementar problemas de optimización presentes en industrias como logística, transporte, supply chain, planificación de recursos y operaciones.

---

# 🎯 Objetivo

Desarrollar proyectos profesionales que permitan resolver problemas complejos mediante modelos matemáticos de optimización, siguiendo buenas prácticas de ingeniería de software y ciencia de datos.

Cada proyecto considera:

- Comprensión del problema de negocio.
- Formulación matemática.
- Implementación del modelo.
- Resolución mediante un Solver.
- Análisis de resultados.
- Visualización.
- Documentación técnica.

---
